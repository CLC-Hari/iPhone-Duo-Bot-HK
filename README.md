Each check now opens a window on top of the desktop with every Hong Kong store's pickup status. If a store has stock, the PC also beeps.

How to run it

Open the folder C:\Users\ChuHarCC\Desktop\IphoneDUObot.
Double-click start_monitor.bat.
Leave that window open. It checks once right away, then again every hour. Click OK to close each popup.
To start it from a terminal instead, open PowerShell in that folder and run:


python monitor.py
Press Ctrl+C in that window when you want it to stop.
